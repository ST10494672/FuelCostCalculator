# EstateAgent

Question 1: Console Application & Unit Tests (50 Marks)

.
EstateAgent.java – Class implementing IEstateAgent
.
EstateAgentSalesReport.java – Main application driver containing the 2D sales matrix and console report output

EstateAgentTest.java – JUnit 5 test suite verifying sales, commission, and top agent logic
.

IEstateAgentGUI.java – Interface for GUI commission calculations and validation
.
EstateAgentGUI.java – Class implementing IEstateAgentGUI
.
EstateAgentReportGUI.java – Main Swing GUI frame with menu bar, form controls, and file export
